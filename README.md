# Калькулятор курсов Aegis

Считает прибыль компании на разнице курсов поставщика и клиента.

- любые валюты и криптовалюты, можно добавлять свои тикеры;
- цепочки конвертаций: RUB → KGS → USD → USDT → …;
- журнал сделок: фильтр по датам, итоги по дням и месяцам, экспорт в CSV (Excel);
- кнопка «Скопировать расчёт» — текст для Telegram/WhatsApp;
- устанавливается на iPhone и Android как приложение (PWA) и работает без интернета.

Пример: объём 10 000 000 RUB, курс поставщика 1,0314, курс клиента 1,025 →
поставщик 10 314 000 KGS, клиент 10 250 000 KGS, прибыль **64 000 KGS**.

## При открытии

Каждый раз калькулятор открывается с одинаковыми значениями: **RUB → KGS**, объём **1 000 000**,
прямой курс «1 RUB = x KGS», курс поставщика — **покупка RUB Бакай Банком** (из загруженных курсов),
курс клиента пустой. Журнал сделок и добавленные валюты сохраняются.

## Курсы

Панель справа от калькулятора — отдельные блоки в таком порядке:

- **USDT/RUB** на биржах (bid / ask);
- **USD/RUB**: ЦБ РФ (официальный), Profinance и Investing.com (bid / ask);
- **банки, обменки, МФК** — покупка и продажа USD, EUR, RUB, KZT, сортировка и фильтры;
- **НБКР** — официальные курсы из XML нацбанка ([nbkr.kg](https://www.nbkr.kg/index1.jsp?item=1562&lang=RUS)): 5 ежедневных и ~43 еженедельных.

Нажмите на поле курса в калькуляторе, затем на курс в панели — он подставится
(для обратной котировки пересчитается автоматически).

Рядом с курсом стрелка ▲▼ — изменение относительно прошлого обновления.
В блоке «Банки и обменки» выбирается банк, чей курс покупки RUB подставляется поставщику при открытии.

Откуда берутся данные (страница берёт самые свежие):

1. при запуске `node server.js` — онлайн через `/api/rates` (кэш 1 минута);
2. **с компьютера казначейства** — `node push-rates.js` раз в минуту отправляет курсы в ветку `rates`
   (файл `rates.json`); так на сайте есть Investing и все биржи, недоступные с серверов GitHub;
3. с серверов GitHub — `rates.json` на Pages, обновляется каждые ~10 минут (`.github/workflows/pages.yml`,
   Investing там пропускается). В **Settings → Pages** источник должен быть **GitHub Actions**.

Сбор курсов — `lib/rates.js` (`node lib/rates.js` печатает JSON).

### Курсы с компьютера

```powershell
node push-rates.js          # раз в минуту, пока окно открыто
node push-rates.js --once   # один раз
```

Токен GitHub берётся из сохранённого входа git (тот же, что для `git push`) или из переменной `GITHUB_TOKEN`.
Чтобы запускалось само при входе в Windows, добавьте команду в Планировщик заданий.

### История курсов

GitHub Actions каждые ~10 минут дописывает сжатую запись в ветку `rates`:
`history/ГГГГ/ММ/ДД.jsonl` — по строке JSON на сбор (биржи, USD/RUB, НБКР ежедневные, банки).

## Запуск на компьютере

Открыть `index.html` двойным кликом — или запустить локальный сервер (нужен Node.js):

```bash
node server.js                  # http://localhost:8080
```

Доступ с телефонов в той же Wi‑Fi сети (PowerShell):

```powershell
$env:HOST="0.0.0.0"; node server.js
```

## Установка на телефон

Нужен адрес `https://` — GitHub Pages: **Settings → Pages → Source: GitHub Actions**.
Сайт: https://chiksan-01.github.io/Calculating/

- **Android (Chrome):** открыть ссылку → «Установить» (или меню ⋮ → «Установить приложение»).
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран «Домой»».

После первой установки приложение работает без интернета.

## Данные

Журнал сделок и добавленные валюты хранятся только в браузере конкретного устройства и никуда не отправляются.
